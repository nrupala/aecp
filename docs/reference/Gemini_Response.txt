### Implementation & Orchestration Instructions for AI Agents (Codex / OpenCode)

When generating code, scripts, or infrastructure definitions based on this architectural blueprint, adhere to the following developer rules:

1. **Zero-Copy Interoperability:** All inter-process communication between analytical tools (e.g., Flink to SINGA or Solr) **must** utilize off-heap Apache Arrow buffers. Avoid linear data conversion ($O(N \cdot M)$) or JNI serialization wrappers to preserve the $O(1)$ memory transit model and maintain target throughput ($92.4\text{ GB/s}$).
2. **Resource Direct-Mapping:** Execute workloads directly through Linux kernel primitives (`cgroups`, namespaces) via Mesos/YARN. Do not introduce extra Docker virtualization daemons to preserve energy targets ($39.7\%$ reduction) and high streaming ingestion rates ($315,000\text{ msg/sec}$).
3. **Hybrid AI & Vector Search Retrieval:** Route RAG workflows by intercepting user notebook input in Zeppelin, running vector similarity search ($512\text{-dim } k\text{-NN}$) and spatial polygon validation in Apache Solr Cloud, and serving inference models via Apache SINGA across GPU/NPU/TPU targets.
4. **Decoupled Tiered Storage:** Maintain ACID operations on Apache Iceberg v3 tables over Apache Ozone object storage, implementing automated lifecycle policies to freeze and migrate historical snapshots to cold Ozone blocks.
